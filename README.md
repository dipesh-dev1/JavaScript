# JavaScript

A collection of JavaScript programs, exercises, and small projects built while learning JavaScript and web development. The code moves from core language fundamentals to working with the browser and asynchronous code, with an emphasis on clean, readable, and well-structured code.

## What this repository covers

- JavaScript basics: variables (`let`, `const`), data types, operators, and type conversion
- Control flow: conditions and loops
- Functions: arrow functions, callbacks, closures, and higher-order functions
- Arrays and objects, including array methods such as `map`, `filter`, and `reduce`
- ES6+ features: destructuring, spread and rest operators, template literals, and modules
- DOM manipulation and event handling
- Asynchronous JavaScript: callbacks, promises, and `async`/`await`
- Working with APIs using `fetch`
- Error handling

## Getting started

### Prerequisites

- A modern web browser
- [Node.js](https://nodejs.org/) (optional, for running scripts outside the browser)
- Git (optional, for cloning)

### Clone the repository

```bash
git clone https://github.com/dipesh-dev1/JavaScript.git
cd JavaScript
```

### Run a script with Node.js

```bash
node filename.js
```

### Run a page in the browser

Open the project's `index.html` file in your browser. The JavaScript runs automatically, and you can view output in the browser console (press `F12`).
